FoloToy 网易云中转服务（Windows 10/11 64 位）

使用方法：
1. 将整个文件夹完整解压，不要只打开 ZIP 内的文件。
2. 双击“启动中转服务.cmd”。
3. 如果 Windows 弹出防火墙提示，请允许在“专用网络”中访问。
4. 记下窗口显示的 Relay URL 和 Registration Code。
5. 手机连接设备热点，打开 http://192.168.4.1，选择家里的 2.4 GHz Wi-Fi，并填写上面两项。

注意：
- 电脑和设备必须连接同一个局域网。
- 使用期间不要关闭中转服务窗口。
- 启动时会强制结束任何占用中转端口 18080 的程序，请勿让其他重要服务使用该端口。
- data 文件夹保存本机注册码、设备信息和网易云登录状态，请勿发给别人。
- 更换电脑后，需要清除设备原配网信息，再使用新电脑生成的注册码重新配置。
- 本程序仅支持 Windows 10/11 64 位。
