# FoloToy 网易云中转版完整包 v1.2.2

这个包包含设备固件和 Windows 中转服务。固件适用于 **ESP32-C3、8 MB Flash、无 PSRAM** 的 FoloToy AI Passport 硬件。

## 1. 烧录固件

固件文件：

```text
firmware/FoloToy-Wangyiyun-full-8MB.bin
```

这是从地址 `0x0` 开始的完整 8 MB 镜像。连接设备后，把下面的 `COM14` 改成设备实际串口：

```powershell
python -m esptool --chip esp32c3 --port COM14 --baud 460800 --before default_reset --after hard_reset write_flash --flash_mode dio --flash_size 8MB --flash_freq 80m 0x0 ".\firmware\FoloToy-Wangyiyun-full-8MB.bin"
```

如果电脑没有 esptool，需要先安装 ESP-IDF，或者执行：

```powershell
py -m pip install esptool
```

## 2. 启动中转服务

1. 完整解压 `server/FoloToy-Wangyiyun-Relay-Windows-x64-v1.2.2.zip`。
2. 双击解压目录中的 `启动中转服务.cmd`。
3. 保持黑色窗口打开，记下窗口显示的 `Relay URL` 和 `Registration Code`。

中转服务不需要另外安装 Node.js、npm 或 Docker。固定端口 18080 被占用时，启动脚本会强制结束占用程序；如果权限不足，请右键用管理员身份运行。

## 3. 首次配网

1. 手机连接设备显示的 `AI-Passport-*` Wi-Fi。
2. 浏览器打开 `http://192.168.4.1`。
3. 从扫描结果中选择家里的 2.4 GHz Wi-Fi，并输入密码。
4. 填写中转窗口显示的 `Relay URL` 和 `Registration Code`。
5. 提交后等待设备重启，再按屏幕提示扫码登录网易云。

电脑和设备必须连接同一个局域网。使用期间不要关闭中转服务窗口。

## 4. 校验文件

`SHA256SUMS.txt` 记录了固件和中转服务 ZIP 的 SHA-256。可以在 PowerShell 中检查：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\firmware\FoloToy-Wangyiyun-full-8MB.bin"
Get-FileHash -Algorithm SHA256 -LiteralPath ".\server\FoloToy-Wangyiyun-Relay-Windows-x64-v1.2.2.zip"
```
