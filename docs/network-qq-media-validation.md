## 已验证

- 主机静态门禁：`tools/validate.sh --static` 通过，25 个 C 主机程序、5 项打包回归、9 项登录工具及仓库检查通过。
- 网络检测模块：31 条路径通过，覆盖 Wi-Fi/IP/时间基础状态、DNS 成功/失败/超时、HTTPS 证书/连接/读写/整轮超时、HTTP 错误响应、取消、忙状态、两槽迟到回调回收和目标白名单。
- HTTP 截止保护：7 组 guard 测试通过；异步连接只在收到连接完成事件前轮询 EAGAIN，响应读取前恢复阻塞 socket，截止时用 `SHUT_RD` 唤醒读取；TLS/HTTP 资源仍由 worker cleanup。DNS/底层同步解析受 ESP-IDF resolver 自身超时约束，不能宣称包含 DNS 的整轮硬上限。
- QQ 媒体：QQ 解析/会话/provider 测试通过；歌词使用官方 `nobase64=1` UTF-8 LRC 公开接口，响应最多 12 KiB、输出最多 8191 字节；封面使用专辑 MID 的官方 90×90 JPEG，设备端有界采样为 60×60 RGB565。封面策略/ROM 回调测试 7 组通过，覆盖域名、尺寸、响应超限、重定向和错误释放。
- UI 预览：早期日/夜两种配色下网络菜单、两页检测结果、暂停提示、封面、歌词和媒体错误共 14 个场景通过。2026-11-11 按用户要求改为单页，成功/失败/播放占用三种状态日夜共 6 个预览重新通过并检查布局；去除翻页、IP/DNS/HTTPS 分项及 HTTP 状态码。
- ESP-IDF 5.5.4 产品构建：通过；应用镜像 3,963,760 字节（`0x3c7b70`），7 MiB factory 分区剩余 3,376,272 字节（`0x338490`）。`verify_firmware.py` 及最终派生打包校验通过；最终产物目录为 `release/FoloMusic-v2.2.0-network-qq-media-final/`，未覆盖既有 2.2.0 release。此前同名目录的覆盖尝试按打包器规则拒绝。
