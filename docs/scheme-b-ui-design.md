## 三键行为

- 列表：上下短按移动、长按跳五项；OK 进入或播放。每层保留光标。
- 播放/暂停：上下短按切歌；OK 暂停/恢复；长按上下进入音量并加减 5%。
- 音量/亮度：上下调节，OK 返回原页；保留原先暂停状态。
- 长按 OK：播放与浏览进入快捷导航；播放时默认我的歌单，浏览时默认返回播放。菜单中长按关闭并回原页。
- 快捷导航含播放、当前歌曲列表、歌单、音量、设置和后续歌词；超出四行上下滚动。实际固件未启用歌词时隐藏其入口。
- 设置子页长按返回上一级；错误页长按回相关页面。退出和重新配网独立确认，默认取消，普通返回不清除任何信息。
- 原型长按阈值 650 ms，未采用双击或组合键。

## 主流程与恢复

首次使用：欢迎 → Wi-Fi 配置 → 连接 → 扫码 → 手机确认 → 登录成功 → 歌单库加载 → 歌单 → 歌曲加载 → 歌曲列表 → 音频缓冲 → 播放。

重复开机：恢复会话 → 歌单；会话失效 → 重新扫码。断网重连后验证会话，不默认再次扫码。

加载成功/失败由原型侧栏的模拟事件触发，不用固定延时冒充网络耗时。空歌单与读取失败分开；空歌单库刷新仍返回歌单库加载，重试歌曲加载返回原歌曲流程。浏览与播放状态独立，暂停后返回保持暂停。

用户切走后，实际固件应使用请求代次或取消标记丢弃过期页面结果；这属于后续实现，HTML 不模拟真实异步请求。固件缓存与 TLS 内存约束仍以体验实施评估为准。

设备连接失败可重试或重新选网，提示密码/频段/信号。退出账号只清会话，重新配网保留旧网络，新网络连接成功后再保存，两者行为均需接入前验证，当前原型仅切页。
