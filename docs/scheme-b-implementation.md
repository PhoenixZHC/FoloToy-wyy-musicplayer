# 方案 B：Folo Music 2.1 实施与验收

2026-11-01：2.1 已完成本地构建和完整镜像打包，尚未以 2.1 版本号刷机。前轮相同功能代码已在设备验证启动、联网、歌单恢复及默认一分钟熄屏。设计过程见[历史状态](archive/development-status-2026-10.md)，当前使用说明与验收边界见[2.1 说明](releases/v2.1.md)。

## 已实现

- 240×320 LVGL 方案 B 日夜界面；独立播放/浏览快照、歌单/歌曲光标、导航、设置、账号、网络与确认流程。
- 本地 Wi-Fi 扫描、QWERTY 三键屏幕键盘、密码显隐/编辑/连接菜单；成功才保存新网络，不保留手机网页配网。
- 网易云 App 扫码授权，NVS 会话保存及开机验证恢复；错误/断网页可进入网络设置更换网络。
- ↑/OK/↓操作提示、Wi-Fi 信号图标、音量、进度；播放/列表顶部不显示指定品牌，不显示顺序播放文案，关于显示真实 PROJECT_VER=2.1。
- 所有页面共用自动熄屏计时，设置位于「设置 → 显示与日夜 → 熄屏」；永不、15/30 秒、1/2/5 分钟，默认一分钟，重启保留，首次按键仅唤醒。
- 北京时间 07:00–19:00 日间，其余夜间；状态条居中显示 HH:mm，未校时显示 --:--，全部状态文字统一 10 像素字号、行高和基线，信号条底部对齐。
- 当前曲封面及同步 LRC 歌词；封面失败不占位，文字恢复全宽；歌名和歌手超宽才滚动，歌词 14 px、两行 42 px 区域。
- 每批八首元数据、每屏四行、三页缓存与有条件相邻预取；最多 512 个歌曲编号滑窗。不缓存离线音频，低内存可跳过预取。
- 9/10/12/14/25 px 各含 6,774 汉字及英文/数字/界面标点，保留原行高基线，真实源覆盖、RLE 回读和位图偏移检查；不额外扩充繁体。字符清单与兼容中转服务同步。

## 容量与烧录

8 MiB Flash：factory 0x10000/0x700000；NVS 0x9000/0x6000、PHY 0xf000/0x1000 不移动。2.1 直连应用 3,897,792 字节，余 3,442,240 字节（约 3.28 MiB）。默认中转兼容构建 3,868,592 字节。没有双槽 OTA。

2.0 正式版历史真机 app SHA-256：15156d0ddab07871e69f4b42f784c98cbd6985a615dd89a19e7c792a7daf3dd1。此前只写 0x10000，写入哈希、分区表/NVS/PHY 比对通过，24,576 字节 NVS 完整保留。

完整发布镜像由构建产物补 0xFF 为严格 8,388,608 字节，不含设备私有数据；从 0x0 烧录会清空 Wi-Fi、账号和显示设置。只有匹配分区表才能使用 app-only 保留设置升级。

## 验证结果与边界

- Build：直连及中转构建、合并镜像逐段校验通过，生产使用 ESP-IDF 5.5.4；正式附件只发布直连。
- Host tests：13 个 C 主机程序、3 个字体测试和新增 4 个打包测试通过。
- Native preview：53 页面×日夜共 106 次渲染，夹具无缺字，检查了简体姓名、英文、版本与隐藏品牌文案；不等于全部页面逐像素对照通过。
- Device tests：前轮 2.0 版本号功能版已验证烧录哈希、设置保留、启动、联网/账号及歌单恢复；自动日夜与默认 60 秒熄屏有串口证据。2.1 仅构建和打包，本轮未刷机。
- Unverified：物理按键唤醒、修改熄屏时间后的重启保存、实机显示效果，以及系统性长时间压力、全部网络/账号/曲库与功耗场景；不宣称所有卡顿已根治或所有页面与 HTML 逐像素完全一致。PassportSim 对本生产版本的完整联网与播放验收未通过支持门槛，诊断结果不可冒充生产验收。

## 仍保留的限制

歌单最多 20 项；隐藏 SSID、企业认证、随机播放切换、离线音频、双槽 OTA 未提供。歌曲版权/会员权限、非官方接口变化和 C3 RAM 预算会影响功能。历史 TLS/DMA/缓存调查见[加载诊断](loading-validation.md)，历史数据不能冒充正式版新测量。
