范围：ESP32-C3 / 8 MiB / 无 PSRAM，独立协议实现，ESP-IDF 5.5.4；预检入口独立于正式播放器。此记录不代表双平台功能全部完成。

| 检查 | 结果与证据 |
| --- | --- |
| 更新范围 | 核对实际分区，私有备份整个 7 MiB 原应用槽；只写 0x10000 应用分区，原应用实际版本 2.0 |
| 现场网络 | 原家庭网络不改；临时 AP/HTTP 配网成功。用户后续授权独立测试网络保存，重启自动读取 `qq_test_wifi`；密码不入源码或日志 |
| 二维码 | 真实 PNG 在设备显示，QQ 音乐 App 扫码确认；SUBACK 后才展示，避免订阅前丢失事件 |
| MQTT | 实机握手、订阅、手机事件和 PINGREQ/PINGRESP 通过；先前发生过网络超时，不将其误报为账号失效 |
| 凭据 | 最终凭据交换、独立 `qqmusic` NVS 保存、主动刷新及校验通过；账号编号按 uint64 十进制原样保留 |
| 歌单和权限 | 真实歌单及歌曲接口通过；遇到无整曲 MP3 权限的歌曲明确跳过，未绕过授权。该账号收藏列表为空，非空收藏待验收 |
| 整曲播放 | HTTP 200，3,924,526 字节；Helix 解码 44.1 kHz、双声道、128 kbps。自然结束 elapsed=244,114 ms，元数据 245,000 ms，预检 ESP_OK |
| 听感及按键 | 用户确认声音及短按 OK 暂停／继续测试正常 |
| 音频稳定性 | 首次完整播放 49 条 timing 报告，全部 underruns=0；无崩溃；最低内部空闲堆 22,568 字节，worker 栈高水位最小 2,716 字节 |
| 重启恢复 | 无重新配网或扫码，读取 QQ 会话、刷新校验、歌单读取及再次 MP3 解码通过；第二次只验证开始播放，不算第二首整曲完成 |

实测应用：3,884,848 字节，SHA-256 `b3a04835294e51d5a7c1ef59fc3e2733f241235ad224d7f99a28bc6735f80a3a`。

测试后已恢复实际原应用槽，整槽 `verify_flash` 校验一致；原槽 SHA-256 `7deb4e2d4cc5461bb51ae7e2b3a642e17874177b2efbf176c1a210f2d94d614f`。未写 bootloader、分区表、原 Wi-Fi、网易云账号或显示偏好；QQ 会话和测试网络保留在各自独立 NVS，原应用不读取测试网络。

本轮修复：ROM PNG 解压包装器在任务栈上分配大型状态，导致栈保护重启；改为有界堆状态并及时释放。登录入口去除 double 精确整数范围限制，避免拒绝大账号编号或在序列化时舍入。HTTP 等待响应超时单独报告，不伪装成响应格式错误。

验证边界：设备预检只涉及本次账号、曲目与现场网络。平台选择、统一设置和退出、平台/账号队列隔离、跨页和自动切歌、封面歌词、网易云回归以及更广泛账号/弱网/长时间压力验收仍未完成。原始日志和设备备份仅在忽略目录；不提交凭据或原始 NVS。
