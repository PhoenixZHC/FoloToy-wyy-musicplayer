# Folo Music 2.3.0

日期：2026-11-11（Asia/Shanghai）。来源设备：Ubuntu 开发电脑。正式版本，本地固件交付及源码推送。

## 本次变化

- 设置内单页网络连通测试，显示检测中、网络连通、网络未连通或检测未完成；后台检查当前平台的 DNS/HTTPS，详细结果只记日志。有效 HTTP 404 也表示服务可达。
- QQ 真实专辑封面和按时间行同步歌词，共享 provider 和界面；封面采样为 60×60，歌词文本有界保留，失败明确提示。
- 只扩展 9、12、24 号歌曲信息字库，各含 12,601 字符；覆盖日文汉字/假名和 2,350 个常用韩文音节。歌手名与歌词统一 12 号，播放歌曲名保持 24 号。
- 状态栏右上角独立电量百分比。CW2017 启动写入默认 80 字节 4.2 V Li-Poly profile，并有界等待就绪，修复 `SOC=0xFE` 导致的 `--%`。默认 profile 未完成本电芯充放电标定，不保证精确剩余续航。
- 音频队列与输入缓冲节省 12 KiB，解码器延迟到首次预缓冲后初始化，修复新增媒体后的 TLS 分配失败。

## 验证与边界

- Build：ESP-IDF 5.5.4 直连构建、内嵌 2.3.0、合并分段、严格 8 MiB、空白区、回读及哈希校验通过。
- Host：25 个 C 主机程序、14 项 Python 回归（5 打包、9 登录工具）、4 项字体测试及仓库/workflow 检查通过；日韩及中英文歌词日夜预览通过。
- Device：本会话 2.2.0 开发包已 app-only 烧录、独立 verify，通过 QQ 联网/会话恢复/歌曲读取和实际解码。用户确认声音、封面、同步歌词、单页网络检测、日韩文字和统一字号、电量百分比正常；日志电量 98% / 4145 mV。完整证据见[实施记录](../network-qq-media-validation.md)。
- Unverified：2.3.0 仅正式版本号构建，本轮未重新烧录。弱网/长期播放、全部媒体异常、完整网易云/平台切换/退出、非空 QQ 收藏及电池完整充放电标定未验收。日韩包一次短时播放记录出现一次断粮并自行恢复，不能宣称长期零卡顿。
- 保留两项既有缺陷：缓冲时暂停可能只改变 UI；异步音频启动成功前提交队列，启动失败不回滚。见[代码审阅](../code-review-2026-11-10.md)。
