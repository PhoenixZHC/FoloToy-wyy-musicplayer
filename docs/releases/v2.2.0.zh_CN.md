# Folo Music 2.2.0

日期：2026-11-10（Asia/Shanghai）；来源设备：Ubuntu 开发电脑。

## 本版变化

- 联网后选择网易云 / QQ 音乐，平台会话独立，统一设置及当前平台账号退出。
- 独立实现 QQ HTTPS、MQTT-over-WebSocket 二维码登录、有界 JSON 解析、歌单分页及有权限的整曲 MP3；无需中转服务器，QQ 封面与歌词尚未接入。
- 增加持久化顺序/随机模式、全歌单队列、上一首历史以及平台/账号/歌单/内容版本隔离；播放模式位于长按 OK 导航第一项。
- 播放前释放浏览缓存，工作页按需分配，QQ 歌单索引精简；切歌先停止旧音频再请求目标页。
- 修正两平台共用文案及切歌加载提示；打包命令新增显式预期版本参数。

## 验证和未完成项

- ESP-IDF 5.5.4 产品直连构建、合并分段、内嵌 2.2.0、严格 8 MiB 打包、回读及哈希校验通过。
- 静态验证：21 个 C 主机程序、14 项 Python 测试通过（9 项登录工具、5 项打包），仓库和 workflow 检查通过。
- 实机仅写应用并独立 verify_flash 通过；启动前 0x0–0xffff 与私有备份相同，保留 bootloader、分区表和 NVS/PHY，启动版本为 2.2.0。首次原网络不可见；用户开启原热点后复测，取得 IP、完成校时并进入平台选择。未重跑登录和完整播放，详见[当前状态](../CONTEXT.md)。
- 此前 QQ 独立预检整曲 MP3、暂停继续及重启会话恢复通过；双平台开发版已有 QQ 浏览和随机跨页切歌实测。这些有日期的结果不作为本次 2.2.0 全套播放重测。
- 仍有两项已知问题：缓冲态暂停可能只改变界面；音频异步启动成功前提前提交队列，失败不回滚。详见[审阅记录](../code-review-2026-11-10.md)。
- 长时间播放/TLS 稳定性、完整随机轮次/上一首、网易云和切换平台/退出回归、非空 QQ 收藏、弱网尚未完整验收。歌曲仍受账号/VIP 权限影响，QQ 无封面和歌词。
