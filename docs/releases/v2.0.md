# Folo Music 2.0

发布日期：2026-10-28。适用设备：FoloToy AI Passport，ESP32-C3，8 MiB Flash，无 PSRAM。

## 功能

- 设备通过开源 EAPI/WEAPI 协议直接访问网易云与音频 CDN，无需部署中转服务器。
- 在设备上扫描 2.4 GHz Wi-Fi，使用三键屏幕键盘输入密码；使用网易云音乐 App 扫码登录。
- 日夜两种配色，支持歌单/歌曲浏览、播放暂停、切歌、音量、进度、快捷导航、网络设置与账号管理。
- 当前歌曲封面和时间同步歌词；封面失败不显示占位，歌名/歌手过长时滚动。
- 歌曲列表分页缓存与相邻页面预取，减少翻页时的重复加载。
- 支持简体中文、英文大小写、数字和常用标点，内置 6,774 个汉字。

标签：`v2.0-folo-music`。以下文件可从本版本的发布附件下载。

完整镜像由构建产物组合，空白区填充 0xFF，**会清空原 Wi-Fi、网易云登录态和显示设置**。不读取或打包任何设备 Flash/NVS。原地升级需先确认分区表匹配，再只写 app；不能在旧 3 MiB 分区设备上直接写 app。

## 兼容性与限制

- 应用大小为 3,883,184 字节，7 MiB 应用分区剩余约 3.30 MiB；完整尺寸和校验值见附件清单。
- 当前最多显示 20 个歌单。
- 支持 2.4 GHz Wi-Fi，不支持隐藏 SSID 和企业认证。
- 暂不支持随机播放切换、离线音频缓存和双槽 OTA。
- 歌曲可播放性受版权、会员权限、网络状态及非官方接口变化影响；首次加载与播放缓冲速度也受设备可用内存影响。
