# Folo Music 2.0

发布日期：2026-10-28。目标：FoloToy AI Passport，ESP32-C3，8 MiB Flash，无 PSRAM。用户实测暂未发现新的问题，并确认将本版本作为正式版。

## 功能

- 设备通过开源 EAPI/WEAPI 协议直接访问网易云与音频 CDN，无需中转服务器或官方开放平台设备参数。
- 设备扫描 2.4 GHz Wi-Fi，使用三键屏幕键盘输入密码；不保留手机网页配网。手机仅用于网易云 App 扫码授权。
- 方案 B 日夜界面、歌单/歌曲浏览、播放暂停、切歌、音量、进度、快捷导航、网络设置、账号与关于页面。
- 当前歌曲封面和时间同步歌词；封面失败不显示占位，歌名/歌手过长时滚动。
- 三页歌曲元数据缓存，每批八首、每屏四首；内存允许时预取相邻页。当前最多显示 20 个歌单，尚未解除该限制。
- 6,774 汉字（完整 GB2312 和 11 个姓名补充字）、英文大小写字母、数字和界面标点；不额外扩展繁体和其他语种。

## 发布文件

标签：`v2.0-folo-music`。本机打包目录：`release/FoloMusic-v2.0/`，二进制作为发布附件，不放入源码提交。

| 文件 | 用途 | 烧录起点 |
| --- | --- | --- |
| FoloMusic-v2.0-full-8MB.bin | 严格 8,388,608 字节完整出厂镜像 | 0x0 |
| FoloMusic-v2.0-app.bin | 已具有匹配 7 MiB factory 分区的设备升级 | 0x10000 |
| manifest.json | 大小、分段及 SHA-256 清单 | 不烧录 |
| SHA256SUMS.txt | 发布文件校验值 | 不烧录 |
| FoloMusic-v2.0-licenses.zip | 上游、组件与字体原始许可证 | 不烧录 |

完整镜像由构建产物组合，空白区填充 0xFF，**会清空原 Wi-Fi、网易云登录态和显示设置**。不读取或打包任何设备 Flash/NVS。原地升级需先确认分区表匹配，再只写 app；不能在旧 3 MiB 分区设备上直接写 app。

## 容量与验收

- 本次真机版本应用 3,883,184 字节，7 MiB 应用分区剩 3,456,848 字节（约 3.30 MiB）。最终附件以 manifest.json 的实际数值为准。
- 构建：直连/中转编译及合并镜像校验通过；正式附件只发布直连版。生产 SDK 为 ESP-IDF 5.5.4。
- 主机：12 个 C 测试程序、4 个发布打包回归、3 个字体测试和 98 次日夜原生页面渲染通过。
- 真机：应用烧录哈希、24,576 字节 NVS 保留、启动联网、账号恢复、20 歌单读取已验证；用户反馈当前暂未出现新 bug。
- PassportSim 不能完整验收本生产版本；诊断版本的配网测试不代表生产固件通过模拟器验收。
- 未完成系统性长时间压力测试、全部曲库/账号权限/网络条件覆盖，不能承诺永不卡顿。非官方接口变化、歌曲版权/会员权限及网络状态可能影响功能。无离线音频缓存或双槽 OTA；隐藏 SSID、企业认证不支持。
