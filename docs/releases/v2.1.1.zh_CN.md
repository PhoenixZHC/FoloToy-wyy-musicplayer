# Folo Music 2.1.1

本地构建日期：2026-11-03，Asia/Shanghai。适用 FoloToy AI Passport：ESP32-C3、8 MiB Flash、无 PSRAM。未创建 Git 标签或公开发布。

## 本次更新

- 播放驱动关闭 Wi-Fi modem sleep，并检查配置错误。
- 下载与解码分离，使用有上限的 16 KiB 队列；启动和断粮后预缓冲 8 KiB，界面显示缓冲状态。
- 有上限的 Wi-Fi 重连和经校验的 HTTP Range/If-Range 恢复，报文不完整时明确失败，不误跳到下一首。
- 音频活动期间暂停推测性元数据预取；播放前和主动浏览完成后释放闲置 API TLS，回收 RAM。
- 保留 2.1 的显示、时钟与自动熄屏功能。

## 验证与边界

ESP-IDF 5.5.4 直连构建、合并分段核验、严格 8 MiB 打包及 4 项打包回归通过。源码交付前完整静态门禁通过：14 个主机程序、4 项打包回归、仓库检查及 workflow 检查。已通过官方 GitHub API 下载固定 actionlint 1.7.12 并核验 SHA-256，之前缺少该工具的限制已解除；前序 3 个客户端重跑结果保留为历史证据。

相同修复代码在版本号仍为 2.1 时已实际烧录：第一首正常播放约 3 分 32 秒并自动切到下一首，第二首继续约 110 秒；61 条已采集 timing 报告累计断粮均为 0，未见播放失败或崩溃标记。释放闲置 API TLS 后，第一首音频初始化后空闲堆由 4,340 增至 31,492 字节。逐字节对比确认差异仅在应用描述及尾部校验字节。本次 2.1.1 仅更新版本元数据，尚未再次烧录，当前设备仍显示 2.1。

人为断开热点后的续传恢复、播放中浏览并发、长期户外弱网、功耗及听感仍待验收，不能用正常播放结果替代。详细实现和历史证据见[热点开发记录](../../firmware/ai-passport/docs/development/hotspot-playback.zh_CN.md)。
