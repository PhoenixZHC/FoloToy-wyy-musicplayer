# Folo Music 2.1

本地固件版本：2.1，构建日期：2026-11-01。适用设备：FoloToy AI Passport，ESP32-C3，8 MiB Flash，无 PSRAM。

## 本次更新

- 新增自动熄屏：在「设置 → 显示与日夜 → 熄屏」选择永不、15 秒、30 秒、1 分钟、2 分钟或 5 分钟，默认 1 分钟，重启后保留。无操作到时关闭背光，音乐继续播放；任意功能键唤醒，首次按键仅唤醒。
- 改进日夜配色：根据系统时间自动切换，北京时间 07:00–19:00 使用日间，其余时间使用夜间；联网校时前显示等待提示并暂用上次保存的配色。
- 新增顶部时钟：所有页面的状态条中央持续显示北京时间 HH:mm，未校时显示 --:--；跨分钟局部刷新，不影响自动熄屏计时。
- 改进状态条排版：名称、时间、WiFi 和电量统一使用 10 像素字号、行高及文字基线，信号条底部与文字对齐。

## 固件与使用说明

产物目录：release/FoloMusic-v2.1/。

| 文件 | 用途 | 烧录起点 |
| --- | --- | --- |
| FoloMusic-v2.1-full-8MB.bin | 严格 8,388,608 字节完整镜像，含 bootloader、分区表和应用 | 0x0 |
| FoloMusic-v2.1-app.bin | 已有匹配分区的设备保留设置升级 | 0x10000 |
| manifest.json | 版本、大小、分段与 SHA-256 清单 | 不烧录 |
| SHA256SUMS.txt | 产物校验值 | 不烧录 |

完整镜像不包含设备凭证，空白区域填充 0xFF；从 0x0 烧录会清空 Wi-Fi、登录态和显示设置。首次启动需重新配网并扫码登录。保留设置升级前须核对 factory 0x10000/0x700000、NVS 0x9000/0x6000 和 PHY 0xf000/0x1000 布局，并私有备份 NVS。烧录命令见[部署与构建](../deployment.md)。

## 验收边界

本版为本地构建交付，不代表已创建远端发布。2.1 直连应用为 3,897,792 字节，7 MiB 分区剩余 3,442,240 字节；完整镜像为 8,388,608 字节。两种构建及合并镜像校验、13 个 C 主机程序、4 个打包测试、3 个字体测试和 106 次日夜原生渲染通过。actionlint 1.7.12 校验及完整静态门禁通过。前轮同功能代码已通过设备启动、联网、歌单恢复及 60 秒熄屏验证；版本号更新后的 2.1 镜像尚未烧录设备。实机显示、物理唤醒及修改超时后的重启保存仍待实际操作验收。
